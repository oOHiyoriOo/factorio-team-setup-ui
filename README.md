# Team Setup UI - Mod Summary

Team Setup UI is a simple admin tool for Factorio 2.0+ that helps with team management in multiplayer scenarios. 
This mod provides a graphical interface for server administrators to create, manage, and configure teams without needing to use complex console commands.

The mod enables admins to create custom teams (forces), assign players to different teams, and configure team relationships with just a few clicks. Key features include a streamlined team creation system, easy player assignment between teams and relationship managment.

Team relationship management is made simple with options to configure cease fire agreements (preventing turret targeting between teams), allied access (allowing building and vehicle access), and map vision sharing (teams share discovered areas). This makes it perfect for various gameplay scenarios: competitive PvP battles, cooperative team challenges, or hybrid competitive co-op modes.

The mod is designed exclusively for admin use, ensuring that only authorized players can modify team structures and configurations. All functionality is accessible through a single command (`/team-ui`), opening a tabbed interface that organizes all team management features logically. The mod is lightweight, efficient, and requires Factorio 2.0+ with the base mod as its only dependency.
